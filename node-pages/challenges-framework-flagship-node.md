# Challenges Framework Flagship Node

## Overview

The Challenges Framework Flagship Node is the place in Euro-BioImaging for testing and comparing artificial intelligence (AI) algorithms that analyse biomedical images. Instead of microscopes or scanners, it offers a digital platform where image-analysis methods are evaluated against shared datasets and compared with each other on equal terms. The Node has a single facility, the Grand Challenge platform at Radboudumc in Nijmegen, which runs the online platform at grand-challenge.org. Its main focus is medical imaging, and Grand Challenge is offered as both a medical and a biological image data service.

The team behind the platform specialises in designing and running image-analysis challenges. In a challenge, organisers provide images with annotations, participants submit their algorithms, and every entry is scored against the same reference in the same way. Staff experience covers benchmarking, reader studies, in which human readers assess the same images, and the reproducible evaluation of algorithms. Submitted algorithms run in a controlled computation environment, which keeps the conditions identical from one entry to the next. This expertise serves research in medical imaging, AI, algorithm validation and clinical decision support.

The Node suits groups who want to set a shared benchmark for a task in medical image analysis, or who need an independent way to validate an algorithm. Researchers who hold an annotated image dataset can work with the Grand Challenge platform to turn it into a public or private challenge. Developers of AI methods for clinical decision support will find a setting where their results can be measured directly against other approaches on the same data.

## Imaging technologies offered

The Node offers one technology, Grand Challenge, which is a digital research platform for algorithms that work on biomedical images. It does not produce images itself. What it lets a researcher measure is how well an image-analysis method performs, and how that performance compares with other methods tested on the same images.

The platform brings together the steps needed for that comparison. Image datasets and their annotations are managed in one place, so the reference against which algorithms are judged stays fixed and documented. Annotation tools allow images to be labelled on the platform. Benchmark challenges then invite algorithms to be tested against this reference, and the evaluation produces results that can be compared across entries.

Algorithms can be submitted as containers and executed on the platform. This means the code runs under the same conditions for every participant, which makes the results reproducible and keeps the test data under the control of the organisers.

Two parts of the infrastructure carry this work. The Grand-Challenge.org online platform is where datasets, challenges and results are hosted and viewed. The controlled computation environment is where submitted algorithms are run and scored. Grand Challenge is offered as a medical image data service and as a biological image data service, so it can host benchmarks built on either kind of image.

## Specialties and research focus

The research served by the Grand Challenge platform sits where medical imaging meets AI. Its application areas are medical imaging, artificial intelligence, algorithm validation and clinical decision-support research. The common thread is a question that every new image-analysis method faces sooner or later, which is how well it really works compared with the alternatives.

Algorithm validation is the centre of this work. A method that performs well on the data its developers used may behave differently on new images, and a shared benchmark with a fixed reference makes that difference visible. Challenges also allow several groups to tackle the same task, so a field can see which approaches hold up and where open problems remain.

Clinical decision-support research is a second focus. Algorithms intended to help clinicians read images need careful evaluation before they can be trusted, and reader studies allow their output to be set alongside the judgements of human readers. Through its registration as a biological image data service, the platform can also host benchmarks built on biological image data.

## Services and user support

Working with the Node usually starts with challenge design and hosting. Staff help organisers shape the challenge itself, which includes defining the task, deciding how entries will be scored and setting up the challenge on the platform so that it can run.

Once a challenge is open, the Node supports data and submission management. The images and annotations that make up the challenge are handled on the platform, and incoming submissions from participants are collected and tracked in one place. This lets organisers concentrate on the science rather than on the logistics of running a competition.

Evaluation is the next step, and the Node offers workflow support for it. Staff help organisers put together the evaluation process that scores each submission against the reference, so that every entry is assessed in the same way.

Throughout the project, the Node provides challenge support for both public and private challenges. A public challenge invites the wider community to take part, while a private one can serve a closed group, for example a consortium validating its own methods before publication.

The Node consists of one facility, the Grand Challenge platform at Radboudumc in Nijmegen. It is a digital platform rather than a laboratory, and its work takes place on the Grand-Challenge.org website and in the computation environment behind it. Researchers therefore interact with it online, through the challenges, datasets and evaluations it hosts, rather than by bringing samples to a physical site.

The facility suits projects that already have images and want to answer a question about analysis. Typical cases are a group that wants to establish a benchmark for a segmentation or detection task, or a developer who needs an independent, reproducible test of an AI algorithm before taking it further towards clinical use. Because every submitted algorithm is run under the same controlled conditions, results from different groups can be set side by side with confidence that the comparison is fair.

The Grand Challenge platform also complements the rest of Euro-BioImaging. Other Nodes acquire images with microscopes and scanners, while this facility provides the setting in which methods for analysing such images can be tested and compared. It covers both medical and biological image data, with its main application areas in medical imaging, AI, algorithm validation and clinical decision-support research.
